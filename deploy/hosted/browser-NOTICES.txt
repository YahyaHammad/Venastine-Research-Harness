Hosted terminal browser notices

Applies to the reviewed textual-serve 1.1.3 wheel:
SHA-256 207a472bc6604e725b1adab4ab8bf12f4c4dc25b04eea31e4d04731d8bf30f18

The JavaScript includes Textual Serve, xterm.js (including canvas, clipboard,
fit, Unicode 11, web-links and WebGL addons), js-base64 3.7.7 and webpack
loader/runtime code. The xterm and loader release references below supply
their license texts; the upstream wheel has no frontend lockfile establishing
all embedded versions. The bridge checks the reviewed JS and CSS hashes.
The CSS also retains its own upstream notice. Unused wheel fonts and images
are not served. These terms cover the browser components, not the harness's
own Apache-2.0 source or the server's complete Python environment.
