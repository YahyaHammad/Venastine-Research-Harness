# ROADMAP_v3 §49 (SS8). The engine for a monitor session's pattern -- a
# regex the MODEL wrote, matched against program output nobody controls,
# inside the harness's own process. Imported by core/line_pattern.py and
# nowhere else.

# RE2 matches in linear time, releases the GIL, and refuses backreferences
# and lookaround at compile time, so the agent is told instead of the
# harness hanging.

# C++ toolchain and Abseil. Another package ships a module named `re2`
# that falls back to `re`, which is why core/line_pattern.py refuses a
# `re2` from any other distribution. What to re-measure when this moves:
# `re2.Options` still has `log_errors` and `max_mem`; a compile error is
